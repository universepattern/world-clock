# World Clock

**Live Demo:** [https://universepattern.github.io/world-clock/](https://universepattern.github.io/world-clock/)

A sleek, responsive, and dynamic World Clock web application.

## About
This browser-based tool allows you to instantly view the current time across multiple global time zones. It features:
- **Real-Time Analog & Digital Displays**: View time down to the second.
- **Dynamic Day/Night Phase Indicators**: Clocks automatically change visual themes (Day, Dawn, Night) based on the time of day in each respective region.
- **Local Time Highlights**: Your current local time zone is automatically detected and highlighted.
- **Global Coverage**: Supports a wide array of international time zones and UTC offsets.
